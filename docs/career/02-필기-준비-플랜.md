# 필기 준비 플랜 (TOPCIT 비즈니스 + NCS)

> 대상: NIA(TOPCIT) / KERIS·산단공단·교통공사·사회보장정보원(NCS·전산)  
> 근무: 9to6, 퇴근 대략 18~21시, 야근 잦음  
> 장비: LG 그램 프로 16 (이동·카페 공부 활용)  
> 목표 공부량: **주 8~10시간** (평일 약 50분 + 주말 모의)

## 2. 공부 원칙

1. **동시 준비 = 공통 70% + 시험 직전 특화 30%**  
2. 평일 목표 **50분**. 21시 퇴근이면 **스킵 or 20분** OK.  
3. 주말: 토 **2.5~3시간**, 일 **2시간**.  
4. 홀수 주 토 = NCS 모의 / 짝수 주 토 = TOPCIT 모의.  
5. 공고 뜨면 **그 시험만 2~3주 올인**.  
6. 인성검사 **최하위 금지** (NIA는 점수와 무관 탈락).  
7. 그램 = 이동·카페용 **보너스**. 본체는 여전히 주 8~10시간.

## 3. 교재 사용법

| 교재 | 사용법 |
|------|--------|
| TOPCIT 에센스 Business | 정독보다 **키워드·프로세스**. 주 2회 챕터 + 모의 |
| NCS 기본서 | 이론 길게 X → **유형 → 문제 → 오답** |
| 초록이 | 기본서 이후 **추가 문제**만 |
| 기사 요약 | **일요일 30~40분**, KERIS·교통공사 전산학용 |

### TOPCIT ↔ NCS 겹치는 코어 (우선 학습)

- 문제해결 / 우선순위 / 원인·대안  
- 프로젝트 관리 (일정, 위험, WBS 감각)  
- 의사소통·문서 이해  
- 자원관리·직업윤리  
- IT 서비스·프로세스 기초
