# 대구·경북 공기업·공공기관 추천 요약

> 작성 기준: Android 네이티브 경력 4~4.5년, 정보처리기사, 금오공대 전자공학부(학점 2.99), 영어 성적 없음, 98년생, 대구·경북 근무 희망  
> 목표: 안정적인 정규직 / 초봉 약 4,000만 원 전후 / 영어 필수 없는 곳 우선

| 항목 | 내용 | 채용에서의 의미 |
|------|------|-----------------|
| 정보처리기사 | 보유 | 전산·교육시스템·IT 직무 우대/가점 |
| 학력 | 금오공대 전자공학부 | **대구·경북 이전지역인재** 해당 가능성 큼 |

| 영어 | 없음 | 영어 **필수** 기관은 보류, 미필수만 우선 |
| 연령 | 98년생 | 청년(만 34세↓) 가점·우대 가능 |

## 3. 기관별 상세

### 3.1 NIA (한국지능정보사회진흥원) — S

| 항목 | 내용 |
|------|------|
| 성격 | 과기정통·행안 산하 준정부기관 |
| 본사 | 대구 동구 첨단로 53 |
| 하는 일 | 국가 AI·디지털·정보화 **정책·사업 기획·관리** |
| 업무 체감 | 코딩 전담보다 **사업계획·예산·성과관리·보고서** |
| 추천 직무 | 공공분야 사업기획·관리 / AI정책 기획·활용 확산 |
| 전형 | 서류 → **TOPCIT 비즈니스 + 인성** → 1·2차 면접 |
| 영어 | 필수 아님 (고득점만 서류 가점) |
| 가점(예시) | 이전지역인재 +2, 청년 +1, 한능검 3급 +1 등 |
| 초봉 | 학사 신입 약 3,500만~3,600만 전후 + 경력환산 |
| 채용사이트 | https://nia.recruiter.co.kr |
| 준비 | TOPCIT 비즈니스, 인성검사, 직무능력기술서 |

**나한테 맞는 이유:** 대구, 영어X, 블라인드, 지역인재·청년, ICT 경력 어필 가능.

---

### 3.2 KERIS (한국교육학술정보원) — S

| 항목 | 내용 |
|------|------|
| 성격 | 교육부 산하 준정부기관 |
| 본사 | 대구 동구 동내로 64 |
| 하는 일 | 교육·학술 정보화 (나이스, K-에듀파인, 디지털교과서, RISS 등) |
| 업무 체감 | **교육 시스템·서비스 구축·운영** (NIA보다 시스템 쪽) |
| 추천 직무 | **교육시스템** (전산·시스템 기획·개발·운영) |
| 전형 | 서류 → **NCS + 직무(전산학 등) + 인성** → 면접 |
| 영어 | 필수 아님 (전공·어학 제한 없는 공고 많음) |
| 초봉 | 약 3,900만 전후(자료별 상이) |
| 채용사이트 | https://keris.recruiter.co.kr |
| 준비 | NCS, 전산학(기사 복습), 자소서 |

**주의:** 정규직 TO가 회차당 소수인 경우 많음. 계약직·인턴은 안정 목표면 선별 지원.

**나한테 맞는 이유:** 대구, 영어X, 기사+앱 경력, 전산학 필기와 궁합.

## 6. NIA vs KERIS 비교

| | NIA | KERIS |
|--|-----|-------|
| 소관 | 과기·행안 | 교육부 |
| 톤 | 정책·사업관리 | 교육 시스템·서비스 |
| 필기 | TOPCIT 비즈니스 | NCS + 전산학 |
| 개발 경력 | 간접(ICT 이해) | 더 직접(시스템) |
| 정규 TO | 한 번에 10~20명대 | 소수인 회차 많음 |
| 채용 빈도 | 상·하반기 | 수시(제N차) |

→ **둘 다 메인**. 필기는 공통 코어 후 공고 직전 특화.
